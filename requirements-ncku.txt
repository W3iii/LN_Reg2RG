# Minimal deps for training/inference on the NCKU ME dataset.
#
# The upstream requirements.txt is a full `pip freeze` of the authors' machine
# (400+ packages: jupyter, streamlit, open3d, moviepy, spacy, medspacy, ...).
# Most are unrelated to Reg2RG and several no longer resolve — open3d==0.14.1
# has no wheel for Python >=3.9, which is what makes `pip install -r
# requirements.txt` fail.
#
# Versions below are the upstream pins for the packages actually imported by
# src/ and evaluation/.
#
# Python 3.10 recommended (transformers 4.28.1 predates 3.11 support).
#
# Install torch FIRST, matched to your CUDA:
#   pip install torch==2.0.1 torchvision==0.15.2 --index-url https://download.pytorch.org/whl/cu118
# then:
#   pip install -r requirements-ncku.txt
